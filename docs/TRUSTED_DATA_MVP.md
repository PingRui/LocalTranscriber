# 可信数据最小闭环

## 目标

把任意行业的视频转写，压缩成一个可立即验收的闭环：输入关键词，找到可信知识片段，并打开原视频定位到对应时间。

## 最小流程

1. 每个视频的结构化转写 JSON 是唯一原始输入，其他 Markdown、TXT、SRT 只作为阅读或字幕导出。
2. 转录任务在正常转写中累计文本，通过远程 API 生成任务分类和热词；不单独创建样本转写任务，也不重复转写首段。
3. 每个文件的全部转录片段一次性发给远程模型；模型只返回局部错误清单，不允许重写、润色或总结全文。
4. 程序核对片段编号和原文位置，并拦截数字、否定词、低置信度和幅度异常的修改；不安全建议只记录、不应用。
5. 每个源文件生成一个 `.verified.json` 和一个 `.corrections.json`。安全修改后的文本和未被提出修改的原文可检索；存在争议的片段不进入可信检索。
6. 验收时输入关键词，结果必须同时返回文本、源视频、开始秒数和结束秒数；“打开视频”在应用内跳到开始时间。

## 文件边界

```text
原始目录（只读）
  001.json
  002.json

本机任务状态（按任务）
  hotword-tasks/<task>.json

可信结果目录（唯一后续入口）
  <source-hash>-001.verified.json
  <source-hash>-001.corrections.json
  <source-hash>-002.verified.json
  <source-hash>-002.corrections.json
```

后续知识库只能读取可信结果目录，不在原始文件、旧 `.llm.*` 文件和可信文件之间自动猜选版本。

## 验收条件

- 能在跨行业任务的正常转录过程中生成相关热词，并让热词实际进入后续 Whisper 识别参数。
- 原始转写不被覆盖。
- 可配置任意 OpenAI Chat Completions 兼容接口；每个文件正常情况下只发起一次整文件校对请求。
- 文件超过所填上下文窗口时必须在调用前停止，不能静默回退为小块校对。
- 接口地址、模型名和 API Key 可保存到项目外的本机配置文件；API Key 不得进入日志、结果或 Git 仓库。
- 任何纠错决定均可回看原文、建议、本地应用结论和原因。
- 搜索只返回可信片段，并能定位到存在的原视频和正确时间。
