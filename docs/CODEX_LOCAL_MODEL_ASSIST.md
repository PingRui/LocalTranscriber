# 让 Codex 协助准备本地模型

这不是固定安装教程。不同电脑的显卡、内存、磁盘和既有软件不同，应让 Codex 先检查当前环境，再一次只给用户一个明确操作。

## 使用方式

1. 在 Codex 中打开 LocalTranscriber 项目目录。
2. 把下面整段“任务指引”发送给 Codex。
3. Codex 完成只读检查后，用户按照它给出的当前一步自行下载、安装或操作界面。
4. 每完成一步就回复 Codex，让它继续检查和验证。

## 交给 Codex 的任务指引

```text
请协助我为当前 LocalTranscriber 项目准备可用于数据清洗和知识库问答的本地模型。

工作目标：
- 最终让 LocalTranscriber 能连接本机 OpenAI 兼容服务。
- 使用设置页中的“检查本地模型”确认连接成功。
- 不修改 LocalTranscriber 的业务代码，不替我构建新的模型服务。

请按以下顺序工作：

1. 先阅读当前项目的 README.md、docs/ARCHITECTURE.md、llm_client.py 和设置页面代码，确认项目实际要求的接口、环回地址限制和模型名称校验方式。
2. 只读检查这台电脑的 Windows 版本、CPU、内存、显卡及显存、可用磁盘空间，以及是否已经安装能提供 OpenAI 兼容接口的本地模型运行工具。
3. 根据真实硬件和已安装软件，只推荐一个最合适的运行方案和一个模型规格。不要一次罗列多套教程，也不要默认项目中的示例模型名称已经存在。
4. 把需要我本人完成的操作拆成一次一个步骤。下载、安装、登录、接受许可、选择模型文件和图形界面操作都由我本人执行；你不要绕过确认自动操作。
5. 每次给出用户操作时，明确说明：
   - 我要操作哪个软件或页面；
   - 这一步要达到什么结果；
   - 完成后我应该回复你什么信息。
6. 我确认完成一步后，再做只读验证并给下一步。不要假设安装或下载已经成功。
7. 服务启动后，检查实际的 OpenAI 兼容地址和 /models 返回值。以服务真实返回的模型 ID 为准，不要凭空填写 qwen3-4b-proofreader。
8. 告诉我应该在 LocalTranscriber 设置页填写的“本地服务地址”和“本地模型名称”，然后让我本人点击“检查本地模型”。
9. 如果检查失败，读取具体错误并定位到服务未启动、地址错误、模型未加载、模型 ID 不一致或资源不足中的一类，再只给一个下一步。
10. 连接成功后，汇总已验证的地址、模型 ID、运行工具和资源注意事项。没有实际验证的项目必须标记为未验证。

安全和资源边界：
- 只允许使用 127.0.0.1、localhost 或 ::1，不要把模型服务开放到局域网或公网。
- 不读取、输出或保存任何 API Key、Cookie、账号凭据或私人转写内容。
- 不删除现有模型、媒体、转写结果或知识库。
- 不下载来源不明的模型或执行来源不明的脚本。
- 在 6GB 显存设备上，不要让 GPU Whisper 与本地 Qwen 同时常驻；先完成并退出转写，再启动本地模型。
- 需要管理员权限、安装软件、下载大文件或改变系统配置时，先停下来让我本人操作。

最终只在以下条件都满足时报告完成：
- 本地服务正在环回地址运行；
- /models 返回了实际模型 ID；
- LocalTranscriber 的“检查本地模型”已经由我点击并显示连接成功。
```

## Codex 应交付的结果

Codex 最终应给出一份很短的确认结果：

- 已验证的本地运行工具。
- 已验证的环回服务地址。
- 服务实际返回的模型 ID。
- LocalTranscriber 连接检查结果。
- 当前设备需要注意的显存或内存限制。

如果用户尚未完成某个操作，Codex 应停在当前步骤，不把“已给出操作方法”描述成“已经安装成功”。
